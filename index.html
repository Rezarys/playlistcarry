Move your NewPipe playlists to FreeTube

FreeTube can import your NewPipe subscriptions, but not your NewPipe playlists. This page opens a NewPipe backup, shows every local playlist and its videos as links, and gives you a playlists file for FreeTube.

In NewPipe, open Settings, then Backup and restore, then Export database. Copy the .zip file to this computer and choose it below. The file is read in your browser and nothing in this page's code sends it anywhere; the page's security policy also stops its scripts from making network requests.

In FreeTube, open Settings, then the Data section, then Import Playlists, and choose this file. FreeTube adds a playlist that has the same name as one you already have to that one, instead of making a second copy. Only YouTube videos go into this file; videos from other services, and playlists you bookmarked in NewPipe, are in the text list.
